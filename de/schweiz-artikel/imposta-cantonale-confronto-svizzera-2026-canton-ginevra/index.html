Insbesondere erhebt der Kanton Zürich eine progressive Einkommensteuer mit Steuersätzen von 0% bis 31,5%. Der Kanton Genf hingegen erhebt eine progressive Steuer mit Steuersätzen von 0% bis 22,5%. Der Kanton Bern erhebt eine progressive Einkommensteuer mit Steuersätzen von 0% bis 12%.

Wenn ein Steuerpflichtiger beispielsweise ein Einkommen von CHF 40.000 hat und im Kanton Zürich wohnt, würde er unter Berücksichtigung des Steuersatzes von 12,5% (CHF 40.000 x 0,125) eine Einkommensteuer von CHF 5.000 zahlen. Wenn derselbe Steuerpflichtige im Kanton Genf wohnen würde, würde er unter Berücksichtigung des Steuersatzes von 10% (CHF 40.000 x 0,1) eine Einkommensteuer von CHF 4.000 zahlen.
